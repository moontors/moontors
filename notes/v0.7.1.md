Moontors 0.7.1

Moontors, the agentic development environment (ADE) for Claude Code, Codex and Gemini CLI, now shows what the agent is doing as it does it: its thinking, each tool from the moment it starts, its background tasks and Claude Code's subagents, with a change to files open on its diff. Links to files open inside Moontors, Files shows icons and git's status, and sessions working in one folder share its terminals and Git view.

What's new:

- The transcript shows the agent at work. Tool calls, notes and denials are light rows under one column of icons, file changes and skills in full white, the rest muted. Thinking shows as Claude Code and Codex sum it up, the last row counts the time of whatever is under way, and background tasks and Claude Code's subagents each get a row you can open. A change to files opens showing its diff. See [What the transcript shows](https://moontors.com/docs/sessions-and-board/#what-the-transcript-shows).
- Send a message while the agent works: Claude Code and Codex take it into the running turn, and Gemini CLI's waits for the turn's end. Stop hands back what the agent hadn't taken yet. See [Sending while the agent works](https://moontors.com/docs/sessions-and-board/#sending-while-the-agent-works).
- A link to a file, in a reply or a tool's row, opens in Moontors: an image or a text file in the preview over the transcript, Markdown formatted with a Source button, any other file in Files with the tree open to it, and a file outside the session's folders in your file manager. Paths show from the session's folder. See [Opening a file](https://moontors.com/docs/sessions-and-board/#opening-a-file).
- A search of the web reads the same from every agent, with the pages it found as links.
- Codex's automatic review puts its verdict on the command's own row. A denial marks the session until you act on it, and **Approve once** is taken once and asks the agent to try again. Claude Code's Auto mode reads the same way. See [Permission modes](https://moontors.com/docs/permission-modes/).
- Files shows each file's type by its icon and git's status by a letter and a colour, with a dot on a folder that holds changes, and git-ignored files dimmed. A click anywhere on a row opens it, a click opens a file in a preview tab that the next one replaces, a double-click keeps it, and the tree's width drags. See [Files](https://moontors.com/docs/diff-and-files/#files).
- Menus open as wide as their items, and in a narrow window the Git view folds its left column by itself so its toolbar stays in reach.
- Sessions working in one folder share its terminals and its Git view. A session started in a worktree's folder works in that worktree, and the worktree stays until the last session in it is archived. A terminal tab renames with a double-click or F2. See [Several sessions in one worktree](https://moontors.com/docs/worktrees/#several-sessions-in-one-worktree) and [Terminal](https://moontors.com/docs/terminal/).
- **Settings** (Cmd+, on macOS, Ctrl+, elsewhere) sets the board's card width and height and the zoom of the transcript inside each card. See [Settings](https://moontors.com/docs/sessions-and-board/#settings).
- Create session keeps presets of the folder, the agent, its model, effort and mode, and the worktree, in an order you drag. A worktree is made on the current commit unless you name a branch. See [Presets](https://moontors.com/docs/sessions-and-board/#presets).
- On the board, a click selects a card and a double-click opens it when the panel is closed, and a right-click offers the session's actions. Every menu names the agent's own default, usage limits show as bars, and times follow your system's 12- or 24-hour clock. See [A card](https://moontors.com/docs/sessions-and-board/#a-card).
- Switching to another account restarts each session once it's at rest, so its connectors and limits load.
- No scrollbars anywhere, the composer floats over the transcript, and pressing a modifier key alone no longer lights up focus rings.
- Events from older sessions that an earlier Moontors didn't recognize now show as what they are.
- The terminal no longer stops drawing after the window reloads, and a busy shell no longer waits on a view that's gone.
- Moontors for Android shows the same rows as the computer, Markdown attachments formatted, and no scroll indicators. A phone still on 0.7.0 keeps working with 0.7.1 on your computer. See [Phone](https://moontors.com/docs/phone/).

The macOS and Windows builds still aren't signed, so each asks once before it opens, and macOS updates through its download page for now. The README's "First launch" and "Updates" sections say what to expect on each platform.
