# Moontors

A desktop app for running many coding-agent sessions at once. Claude Code, Codex and Gemini CLI
sessions sit side by side on one board, each showing its transcript live, and a background service
keeps them running when the window is closed.

This repository holds Moontors' releases and its issue tracker.

## Download

Moontors isn't released yet. Each version will be on the
[Releases](https://github.com/moontors/moontors/releases) page, for macOS, Windows and Linux.

## Report a problem or ask for a feature

Open an [issue](https://github.com/moontors/moontors/issues/new/choose). For a problem, include
the build line from Moontors' `/status` or About, which names the exact version.
