Moontors 0.7.7

Moontors, the agentic development environment (ADE) for Claude Code, Codex and Gemini CLI, runs Claude Code 2.1.309, Codex 0.164.0 and Gemini CLI 0.65.0. Claude Code and Gemini CLI sign in through Google Cloud's Vertex AI, and Claude Code through Microsoft Foundry too, the Accounts button shows a ring for each usage limit near its end, and whatever you send brings the transcript back to its newest line.

What's new:

- Claude Code and Gemini CLI sign in to Google Cloud's Vertex AI: choose **Sign in with Vertex AI**, then **Your gcloud sign-in on this computer**, **The credential file your environment names** or **A credential file**, or with Gemini CLI **A Google Cloud API key** for Vertex AI's express mode; then check the **Project ID** and give a **Location**, or with an API key the key alone. **Accounts** shows the sign-in as Vertex AI. Moontors hasn't tried it against a real Google Cloud project yet. See [Ways to sign in](https://moontors.com/docs/sign-in/#ways-to-sign-in).
- Claude Code signs in to Microsoft Foundry: choose **Sign in with Microsoft Foundry**, then **Your Azure CLI sign-in on this computer** or **The Foundry API key your environment sets**, or give **A Foundry API key** or **An Azure bearer token**, then the **Resource name or endpoint URL** and the deployment each of Claude Code's model families runs on. **Accounts** shows the sign-in as Microsoft Foundry, and a session's model list offers **Change deployments…**. Moontors hasn't tried it against a real Azure resource yet. See [Ways to sign in](https://moontors.com/docs/sign-in/#ways-to-sign-in).
- The **Accounts** button shows a ring for each usage limit at 75% or more, as Claude Code's 5h window and its weekly limit each have their own: amber, then red from 90%, filled to how much is used, with the percentage inside. Point at a ring for the agent, the account, the window, how much is used, when it resets and how long ago Moontors heard it. A ring stays until its window resets or newer figures are under 75%, and figures 15 minutes old are read again while Moontors is in front. On the phone, the rings sit after the Accounts icon on the board; tap them for the same. See [The header](https://moontors.com/docs/window/#the-header).
- Whatever you send from the composer, a message, one that waits for the turn to end or a command, brings the transcript back to its newest line however far up you'd read, and it keeps to it as the reply comes. A message sent from another window or your phone leaves this one where you're reading. See [The composer](https://moontors.com/docs/sessions-composer/).
- A turn's footer says the day it ended where that was an earlier one: yesterday at 1:21 AM, or 46 days ago at 1:21 AM, always in days, and it moves on at midnight with the transcript open. An exported transcript gives each turn's date instead. On the computer and the phone. See [A turn's footer](https://moontors.com/docs/sessions-transcript/#a-turns-footer).
- A Claude Code skill that runs in its own context, as `/code-review` does, shows the same two rows whether you typed it or Claude Code chose it: **Skill** and its name, then a row such as "`/code-review` in its own context" holding the skill's steps as they happen. See [Tools and subagents](https://moontors.com/docs/sessions-tools/).
- On the phone, while the keyboard is up, **Hide keyboard** floats just above the composer's right corner and puts it away, and anything you send puts the keyboard away too. The way back to the board is a back arrow and its word, bigger and easier to tap. See [The composer](https://moontors.com/docs/phone/#the-composer).
- Fixed: on Windows, a Claude Code file denial offers **Allow for this session** too. See [Allow for this session](https://moontors.com/docs/permission-modes/#allow-for-this-session).
- Fixed: on an iPhone with the local network refused, a scanned QR code reaches your computer's tailnet address at once, or after one wait for iOS's own question, instead of waiting on each of the computer's local addresses first. See [Pairing](https://moontors.com/docs/phone/#pairing).

Moontors for iPhone is offered in every country and region but China mainland.

The Windows and Linux builds still aren't signed, so Windows asks once before Moontors opens. The README's "First launch" and "Updates" sections say what to expect on each platform.
