Moontors 0.8.9

Moontors, the agentic development environment (ADE) for Claude Code, Codex, Gemini CLI, Grok Build and OpenCode, still runs Claude Code 2.1.325, Codex 0.169.0, Gemini CLI 0.68.0, Grok Build 1.0.77 and OpenCode 2.3.0. This release lets you restart a session's agent without restarting Moontors, and makes the error tag and the first launch's welcome session behave as you'd expect.

What's new:

- **`/restart`** ends a session's agent and starts it again on the same conversation, without restarting Moontors. Before it starts, Moontors reads your environment again, so a tool you installed since Moontors started, such as Node or uv for an MCP server that couldn't start, is found by this agent and every one started after it. Where it would end something, it asks first and names it: the turn under way, background tasks, subagents, a goal or a scheduled wake-up. Messages waiting for the turn's end stay, paused. Every agent has it, on your computer. See [The built-in commands](https://moontors.com/docs/conversation-commands/#the-built-in-commands).

What's changed:

- The header's **error** tag counts a session only until you've seen its error: once it's open in the panel of the window you're in, or open in Moontors' Android app with it in front. Its card still says Error, and its next failure counts again. See [The header](https://moontors.com/docs/window/#the-header).
- The first time Moontors opens, it makes its free welcome session only once OpenCode's free model answers a tiny prompt from your network. On a network whose shared address has already used OpenCode's free limit, as an office's, a university's or a VPN's can, or offline, there's no welcome session to fail on your first prompt. If you open a page or a dialog while it checks, the welcome waits on the board instead of taking you away. See [OpenCode](https://moontors.com/docs/sign-in/#opencode).

This version updates the Android app; the iPhone app isn't updated this time. The Windows and Linux builds still aren't signed, so Windows asks once before Moontors opens. The README's "First launch" and "Updates" sections say what to expect on each platform.

Found a problem, or have an idea? Open an issue: https://github.com/moontors/moontors/issues/new/choose
