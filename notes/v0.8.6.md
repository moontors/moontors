Moontors 0.8.6

Moontors, the agentic development environment (ADE) for Claude Code, Codex, Gemini CLI and Grok Build, now runs Claude Code 2.1.322, Codex 0.167.1 and Gemini CLI 0.68.0. This release brings the board in a window of its own, for working across two displays; a List layout for the board, and a switch for the transcript on its cards; board settings of its own for each window; and copying a file itself from the file viewer.

What's new:

- **Board in its own window**, the first of the header's icons, moves the board to a window of its own, on your other display where you have one, with the same state tags above it. This window keeps everything else, its tags too, and the transcript panel takes the board's room. Click a card there to show its session in this window's panel, and the board's window stays in front so you can go on clicking; double-click it, or press Enter on it, to open the session here. While the board is away, the button draws arrows pointing in and is named **Bring the board back here**. Moontors keeps whether the board is in its own window, and where that window was, after a restart or an update too. See [The board in its own window](https://moontors.com/docs/window/#the-board-in-its-own-window).
- The board has a third layout, **List**: its sections one below another, as in rows, and each section's cards one below another too, each as wide as the board, so the board scrolls only down. In a list the board can be as narrow as 250 pixels, half what rows and columns need, so the transcript panel can take more of the window. See [Settings › Board](https://moontors.com/docs/settings/#board).
- **Transcript on the cards**, in Settings › Board, on as it starts: off, a card is its title and age, its status, its agent, its folder, the bell and the context meter, every card the same height, each item cut short on its one line where it has less room. See [Settings › Board](https://moontors.com/docs/settings/#board).
- Settings › Board has two cards, side by side where there's room, **Main window** and **Board in its own window**, each with every board setting of its own, so the board's window can show, say, rows with the transcript, while the main window keeps a list with none beside the panel to move between sessions. Until you change one on **Board in its own window**, the board there looks as the main window's does. Its **Show the board in the main window too**, off as it starts, keeps a board in the main window too, beside the panel, while the board has its own window. See [Settings › Board](https://moontors.com/docs/settings/#board).
- In the file viewer, Cmd+C (Ctrl+C on Windows and Linux) and a right-click's **Copy file** copy the file itself, as your file manager copies one, so it pastes into Finder, Explorer or a chat as the file, an image as its picture as well. The copy button beside the X, a copy icon with a chevron, offers **Copy file**, **Copy file name**, **Copy relative path** and **Copy full path**. See [Opening a file](https://moontors.com/docs/sessions-attachments/#opening-a-file).
- With Claude Code 2.1.322 on Vertex AI, fast mode runs where your sign-in's location is global, us or eu, and the **Fast** chip offers it there. See [Session settings](https://moontors.com/docs/configuration/#session-settings).
- On moontors.com, [Articles](https://moontors.com/articles/), each article a page of its own with the others in a side menu and Previous and Next at its foot, one also in Hebrew; code blocks in Moontors' own colours; and the board in its own window among the key features and on the comparison pages.

This version updates the phone app on Google Play, with nothing you'll see change there; the iPhone app isn't updated in this version. The Windows and Linux builds still aren't signed, so Windows asks once before Moontors opens. The README's "First launch" and "Updates" sections say what to expect on each platform.
