Moontors 0.1.0

The first public release of Moontors, an agentic development environment (ADE) for running Claude Code, Codex and Gemini CLI side by side, on macOS, Windows and Linux. It's an early preview: ready for daily use, with rough edges we want to hear about.

What's in it:

- Every agent on one board: Claude Code, Codex and Gemini CLI sessions side by side, each streaming its work live, in your own sections and filtered by project.
- Sessions run in a background service, so they keep working when the window is closed.
- Permission modes from Manual to Bypass, with Allow and Deny right in the transcript.
- A git worktree and branch per session when you want one, with archiving that asks before removing work.
- A diff of each session's changes, and a file editor beside the agent that never overwrites its work or yours.
- The agents' own slash commands, plus /rewind, /compact, side questions, subtasks, forks, /export and @ file mentions.
- Your agents' own settings, MCP servers, skills and commands, used as they are.
- Context, token usage and your account's limits on every card.
- No Moontors account, no telemetry and no tracking.

The macOS and Windows builds aren't signed yet, so each asks once before it opens, and macOS updates through its download page for now. The README's "First launch" and "Updates" sections say what to expect on each platform.

Found a problem, or have an idea? Open an issue: https://github.com/moontors/moontors/issues/new/choose
