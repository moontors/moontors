Moontors 0.5.0

Moontors, the agentic development environment (ADE) for Claude Code, Codex and Gemini CLI, now takes files with a message, lets you switch an agent's account without signing out, and gives Codex everything its plugins bring, as Claude Code and Gemini CLI already had.

What's new:

- Attach files to a message with the + button beside /, or drag them anywhere onto the transcript. They sit above the message as chips, each with an X to take it off. Each file can be up to 5 MB.
- Click a chip to look at its file: images as they are, text and code in a read-only editor. Other files, and any too large to preview, show their name. A sent message keeps its chips.
- Claude Code and Gemini CLI take images, PDFs and text files, and Codex takes images and text files. A file the agent can't take is refused before sending, with why.
- A message whose files would go with a command the agent runs, such as /review, is refused with why.
- A new Accounts button, at the header's right end, shows each agent's sign-in: the account, how it signed in, and its usage and limits.
- Switch account goes straight to the agent's sign-in, with no sign-out first. Running sessions go on with the new account, at once where the agent can take it, otherwise from their next turn. Sign out is there too.
- Codex plugins now reach Codex whole, as Claude Code's and Gemini CLI's already did: their skills and commands, MCP servers, hooks and apps. One switch per plugin turns all of it off.
- Plugins your claude.ai or ChatGPT account adds, claude.ai's connectors and Codex's apps now show in an agent's configuration, each with its own switch, and a connector or app that needs signing in has an Authorize button.
- A Claude Code plugin's settings and secrets now reach it: its settings from your own Claude Code settings, its secrets from where your Claude Code keeps them, read only when a plugin needs one. Moontors passes only the secrets of the plugins it runs, and keeps none of them once that run of the agent ends.
- A Gemini CLI extension's own policy rules show in its configuration, as Gemini CLI applies them.
- Remove Moontors' Data now names each file an agent keeps for itself, such as Claude Code's ~/.claude/.device-keys.json.
- The docs now explain every part of Moontors: each view, among them the Plan view, the transcript and the composer, the questions and plans agents bring, every dialog and menu, and what each agent can do.

The macOS and Windows builds still aren't signed, so each asks once before it opens, and macOS updates through its download page for now. The README's "First launch" and "Updates" sections say what to expect on each platform.

Found a problem, or have an idea? Open an issue: https://github.com/moontors/moontors/issues/new/choose
