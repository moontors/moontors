Moontors 0.7.2

Moontors, the agentic development environment (ADE) for Claude Code, Codex and Gemini CLI, now lets you talk to your agents as you would to people: reply to a row of the transcript, have the agent rephrase what you've typed, and let sessions message each other. Files works as a code editor's explorer does, with Go to File, search and replace, previews and its menus, and the Git view gains columns and a commit panel.

What's new:

- Reply to any row of the transcript, or to words you select in one, as you'd reply to a message: the quote rides above your message, the agent reads it as a quote, and a click on it goes back to the row. On the phone, press and hold a row. See [Replying to a row](https://moontors.com/docs/sessions-and-board/#replying-to-a-row).
- **Rephrase**, beside Attach in the composer, has the session's agent rewrite what you've typed, as it is or slightly enriched; Settings picks which one a click does, and Undo brings your own words back. Nothing of it reaches the conversation. See [Rephrasing a message](https://moontors.com/docs/sessions-and-board/#rephrasing-a-message).
- Sessions can message each other, whatever their agent: each session's agent can list the other open sessions and send one a message, which arrives as from that session. See [Sessions messaging each other](https://moontors.com/docs/sessions-and-board/#sessions-messaging-each-other).
- Cmd+P (Ctrl+P on Windows and Linux) opens Go to File from anywhere, a search over the session's files and folders that opens a file in Files, and the tree follows the file you're in. See [Going to a file](https://moontors.com/docs/diff-and-files/#going-to-a-file).
- Search and replace across the session's files, as in VS Code: Match Case, Whole Word and regular expressions, Replace All with Preserve Case, and the files to include and exclude. Cmd+Shift+F (Ctrl+Shift+F) opens it. See [Searching the files](https://moontors.com/docs/diff-and-files/#searching-the-files).
- The Files tree works as VS Code's: New File, New Folder and Collapse Folders, rename and open by VS Code's keys, drag a file or folder to move it, drop or paste files from your computer to copy them in, and a right-click menu with Cut, Copy and Paste, Copy Path, Rename, Delete to the Trash, Reveal and Find in Folder. See [The tree's menu and keys](https://moontors.com/docs/diff-and-files/#the-trees-menu-and-keys).
- Files, and the transcript's preview, show what they can't edit: images with fit, 100% and zoom, an SVG with its source a toggle away, fonts, video and audio, PDFs, and CSV and TSV as a table. See [Previews](https://moontors.com/docs/diff-and-files/#previews).
- The Git view has column headers and panes you can resize, a Branch / Tag column, a commit panel that shows **Signed** on a commit git verifies, a find that searches as you type, and a Fetch button whose menu picks a pull or a push as its default. Every diff in Files and Git is drawn by the editor. See [Git](https://moontors.com/docs/diff-and-files/#git).
- The views keep their state across a restart: the Git view as you left it, each session's Files tabs, open folders and search, and the terminal's tabs by name and order, each coming back as a fresh shell. See [Files](https://moontors.com/docs/diff-and-files/#files) and [Tabs](https://moontors.com/docs/terminal/#tabs).
- The transcript's edit rows are coloured as Files colours code, with the words that changed in a line marked. See [What the transcript shows](https://moontors.com/docs/sessions-and-board/#what-the-transcript-shows).
- Archiving asks every question before anything stops, the running terminals first and then a worktree's changes and the branch it keeps, so Cancel leaves the agent and its shells running. See [Archiving](https://moontors.com/docs/worktrees/#archiving).
- A sign-in, a sign-out or an account switch made in any window shows at once in every window and on the phone. See [Accounts](https://moontors.com/docs/sign-in/#accounts).
- Where your organization deploys a managed MCP config for Claude Code, Claude Code sessions and `/btw` start there: Moontors passes Claude Code no MCP server, its own included, so those sessions can't message the others, and the transcript says so. See [Known limits](https://moontors.com/docs/known-limits/#sessions).
- Gemini CLI sessions show how full their context is in the ring, as the other agents' do.
- The `/` list says when nothing matches, as the `@` list does, Collapse Folders leaves the top folders open, the composer's file row scrolls to a file as you add it, and the views over the board open in place.
- Moontors for Android replies to a row on a press and hold, rephrases with the composer's own button, shows sessions' messages to each other, and colours code and the lines a tool changed as the computer does, including shell commands and Markdown, which it had left partly plain. See [Phone](https://moontors.com/docs/phone/).
- The Terms of Use say that a feature free today may become part of a paid plan, which the app and the release notes will say before it does.

The macOS and Windows builds still aren't signed, so each asks once before it opens, and macOS updates through its download page for now. The README's "First launch" and "Updates" sections say what to expect on each platform.
